# Humanizer-zh 模式清单（正文检查点详解与标题检查）

本文件是 [`SKILL.md`](../SKILL.md) 的配套参考，不单独执行。模式判定、清单格式和复核流程都在 `SKILL.md`。

- 版本：2026-11-05。条目与 `SKILL.md` 的速查表一一对应。改条目时同步分组文件和速查表。
- 用法：进入「列命中」时按组读，一次只读一个分组文件，读完写下本组命中再读下一组；不要凭记忆判断。
- 边界：这些是编辑问题的检查线索，不证明文本来自 AI。单个词、标点、三项列表或四字词不是修改理由。

清单一次看不完是正常的，边读边摘，回头核对。判定靠读原句，不靠数条目；一条会不会命中，取决于它在这一段里有没有造成空泛、重复或歧义，而不取决于它是否出现在词表里。示例均为教学用文本；改写只能使用“改写前”包含的信息，“保留”示例展示不应修改的边界。

## 标题检查

[T1–T6](H.md) 是单独模块，不占正文检查点的编号，只在标题进入编辑范围时读：用户要求检查、修改或拟标题，用户要求审阅整篇文档，或交付形态把分节标题拆掉。先连读所有标题（T1），再看单条标题是否在裁判（T2）、位置（T3）、语域（T4）、题文是否相符（T5），最后看层级格式（T6）。
